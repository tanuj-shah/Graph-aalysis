# Nepal Oil Corporation Pricing Dashboard

Simple, Nepal-focused petroleum pricing dashboard for presentation use.

## Files
- `noc_dashboard.html`: main dashboard UI (single-page, simplified)
- `noc_petroleum_pricing_2026-04-03.csv`: extracted source dataset
- `noc_petroleum_pricing_2026-04-03_cleaned_standardized.csv`: standardized data
- `noc_petroleum_pricing_2026-04-03_quality_report.json`: data quality report
- `convert.js`: conversion/extraction helper script

## Run locally
1. Install dependencies:
   npm install
2. Open `noc_dashboard.html` in your browser.

## Notes
- Currency presentation is optimized for Nepal (NPR).
- Dashboard defaults are aligned with source baseline values.
